# Katalog Kategori Produk Elektronik

## Deskripsi Singkat Program

Katalog Kategori Produk Elektronik merupakan program berbasis Python dengan tampilan Command Line Interface (CLI). Program ini digunakan untuk mengelola data produk elektronik berdasarkan kategori, merk, series, harga, deskripsi, dan stok. Data produk disimpan secara permanen menggunakan file teks, sehingga data tetap tersedia meskipun program telah ditutup.

Program ini dibuat sebagai proyek akhir Project-Based Learning (PBL) Mata Kuliah Algoritma dan Struktur Data. Dalam implementasinya, program menerapkan beberapa struktur data seperti Dictionary, Double Circular Linked List, Stack, serta algoritma Sequential Search dan Sorting menggunakan fungsi `sorted()`.

## Fitur Program

Program ini memiliki beberapa fitur utama, yaitu:

1. Menampilkan data produk elektronik.
2. Menambahkan data produk baru.
3. Mengubah data produk, kategori, dan merk.
4. Menghapus data kategori, merk, series, dan riwayat update.
5. Mencari data berdasarkan kategori, merk, dan series.
6. Mengurutkan data produk berdasarkan harga termurah dan termahal.
7. Menampilkan riwayat update data produk.
8. Menyimpan data produk dan riwayat update menggunakan file `.txt`.

## Struktur File

Berikut struktur file pada proyek ini:

```text
ASD_B1_20/
│
├── Program_Katalog_Elektronik.py
├── kategori.txt
├── riwayat_update.txt
└── README.md
```

Keterangan file:

* `Program_Katalog_Elektronik.py`
  File utama yang berisi seluruh source code program.

* `kategori.txt`
  File untuk menyimpan data produk elektronik, seperti kategori, merk, series, harga, deskripsi, dan stok.

* `riwayat_update.txt`
  File untuk menyimpan catatan perubahan data setelah proses update dilakukan.

* `README.md`
  File dokumentasi singkat mengenai proyek.

## Cara Menjalankan Program

1. Pastikan Python sudah terinstal pada perangkat.
2. Buka folder proyek menggunakan VSCode atau terminal.
3. Pastikan file `Program_Katalog_Elektronik.py`, `kategori.txt`, dan `riwayat_update.txt` berada dalam satu folder.
4. Jalankan program dengan perintah berikut:

```bash
python Program_Katalog_Elektronik.py
```

5. Setelah program berjalan, pengguna dapat memilih menu yang tersedia sesuai kebutuhan.
